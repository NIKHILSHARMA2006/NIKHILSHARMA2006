### 🤖 AI Weather & Movie Agent

* 🌦️ Retrieves weather information using Open-Meteo.
* 🎬 Searches for movies using TMDB.
* 🧠 Uses LangChain and Ollama for AI-powered query handling.
* 🐍 Built with Python and Flask.

**Tech:** Python · Flask · LangChain · Ollama · Open-Meteo · TMDB
